## Major
### 🟠 Reordering place results ahead of organic results breaks `test_search_organic_and_places_normalized`, `backend/src/functions/evidence_collector/serpapi_adapter.py:285`
**Problem**: In `SerpApiAdapter.search`, place and local results are now parsed and appended to `results` before organic results. However, `backend/tests/unit/test_serpapi_adapter.py:88-89` asserts that `results[0]` is the first organic observation (`assert obs1.publisher == "kolkatatrafficpolice.gov.in"`). Because results now prepend place observations, `results[0]` is `dakshineswartemple.org`, causing the unit test to fail with an `AssertionError`.
**Why it matters**: Breaks continuous integration test runs in `tests/unit/test_serpapi_adapter.py`.
**Suggested fix**: Update `test_serpapi_adapter.py` to assert against `results` using content/locator matching or adjust index expectations to match the new local-results-first ordering.

### 🟠 `PERMITTED_CONTRACT_FILES` omits `candidate.py`, causing isolated worker import failure, `backend/src/functions/route_optimizer/packaging.py:43`
**Problem**: `functions.orchestrator.places.schemas` subclasses `CoordinatePoint` from `contracts.candidate`. When `build_route_optimizer_artifact` builds the isolated route optimizer package, it copies `schemas.py` and copies only the contracts listed in `PERMITTED_CONTRACT_FILES` (`routing.py`, `money.py`, `trips.py`). `contracts/candidate.py` is not copied.
**Why it matters**: In isolated runtime packaging and deployment artifacts, importing `functions.route_optimizer.consumer` crashes with `ModuleNotFoundError: No module named 'contracts.candidate'`. This breaks 4 standalone packaging tests: `test_route_optimizer_packaging_within_limits`, `test_isolated_environment_import_verification`, `test_packaging_cli_entrypoint`, and `test_dependency_inclusive_python312_linux_artifact`.
**Suggested fix**: Add `"candidate.py"` to `PERMITTED_CONTRACT_FILES` in `backend/src/functions/route_optimizer/packaging.py`.

## Minor
### 🟡 Hardcoded `min(2, max_slots)` unconditionally overrides environment configuration, `backend/src/functions/orchestrator/graphs/trip_planner/graph.py:3010`
**Problem**: In `escalate_dynamic_evidence_node` (line 3010) and `route_evidence_decision_node` (line 3417), `max_slots = min(2, max_slots)` unconditionally clamps `max_slots` to 2. Even if an operator or test explicitly configures `BROWSER_MAX_ESCALATION_TASKS=4`, it is clamped back down to 2.
**Why it matters**: Prevents operator override in production and breaks `test_escalate_dynamic_evidence_node_configurable_budget_ceiling` which validates environment configuration.
**Suggested fix**: Set the default value of `BROWSER_MAX_ESCALATION_TASKS` to 2 in configuration/settings or fallback defaults rather than hardcoding a clamping operation that overrides explicit settings.

### 🟡 Backend typecheck `mypy src` in `verify.sh` reports 40 type errors, `verify.sh:14`
**Problem**: `verify.sh` runs `uv run ruff check . && uv run mypy src`. While ruff passes cleanly with zero errors, `mypy src` reports 40 type errors across 14 files (primarily checkpointer base serializer signatures and protocol types, `TransportMode` enum attributes in `costs.py`, and `ArtifactRepositoryPort` method signatures).
**Why it matters**: Running `./verify.sh` halts at step 1 due to typecheck failures.
**Suggested fix**: Address the type mismatches or configure mypy in `pyproject.toml` with module-specific overrides until checkpointer protocols are fully aligned.
